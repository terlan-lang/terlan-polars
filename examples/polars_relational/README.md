# Polars relational operations

Exercises independently named join keys, all equi/cross join modes, typed
cardinality validation, deterministic row-order policies, expression-driven
non-equi joins, typed row deduplication, null-row removal, head/tail endpoint
selection, bounded slicing, bounds-safe indexed gathering with optional null
rows, configurable multi-key ordering and top/bottom-row selection,
schema-preserving clearing, chunk consolidation,
column renaming/removal, row reversal/indexing and shifting, whole-frame
missing-data cleanup, null-count summaries, whole-frame arithmetic and
statistical column reductions, exact and approximate cardinality summaries,
lazy schema resolution and cache
nodes, lazy execution, and vertical, horizontal, and diagonal concatenation.

```bash
terlc run examples/polars_relational
```
